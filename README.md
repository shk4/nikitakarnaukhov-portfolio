# Портфолио Никиты Карнаухова

Полный проект портфолио: страницы, тексты кейсов, стили, анимации, обложки, изображения, видео, шрифты и настройки самостоятельного размещения.

Актуальная тестовая версия: https://nikita-portfolio-workbench.karnauhovnikita.chatgpt.site/. Снимок версии 45, исходный коммит `84dc2bb81d07f1e4e6c5d402912f4ba69981a6c6`. Включены последние изменения интерфейса, медиа, резюме и удаление пиксельных квадратов.

## Быстрый старт

Нужны Node.js 22.13 или новее и npm.

```sh
npm ci
npm run dev
```

## Готовый сайт для сервера

```sh
npm run build
npm run validate:artifact
```

Готовые файлы находятся в **`dist/client/`**. Загрузи содержимое этой папки в корень сайта. Для работы готовой сборки не нужны Node.js, база данных или аккаунт прежнего хостинга.

Инструкция для Nginx, Apache и Docker — **[DEPLOY-RU.md](DEPLOY-RU.md)**. Конфигурация Nginx находится в `deploy/nginx.conf`, Apache — в `public/.htaccess` (после сборки она копируется в `dist/client/.htaccess`).

Для Docker подготовь отдельную папку: скопируй туда содержимое `deploy/`, папку `dist/client` скопируй под именем `www`. Затем выполни `docker compose up -d --build` из этой папки. Контейнер слушает `127.0.0.1:8080` для подключения существующего reverse proxy.

Сайт рассчитан на размещение в корне домена, а не в подпапке. Сохраняй `.rsc`-файлы: они нужны для переходов между страницами. Конфигурации сервера уже учитывают их MIME-тип и запрос `/.rsc`.

## Структура

- `app/` — страницы, компоненты, CSS и клиентские анимации.
- `content/` — тексты пяти кейсов.
- `public/media/` — изображения, обложки и видео.
- `public/resume/` — резюме.
- `design-sources/` и `scripts/design/` — исходные материалы для иллюстраций и анимаций.
- `deploy/` — конфигурации для самостоятельного хостинга.
- `scripts/check-static-export.mjs` — проверка сборки и локальных ресурсов.

Главная страница находится на `/`, кейсы — на `/cases/…`. Архивные эксперименты исключены из актуальной версии.

## Технологии и проверка

React 19, TypeScript, Vinext/Vite и статический экспорт. Шрифты и основные медиафайлы локальные. По кнопке можно открыть внешние Figma-вставки; ссылки на Figma и Telegram сохраняют обычную зависимость от этих сервисов.

`npm test` выполняет сборку и проверяет созданные страницы, локальные ссылки, файлы переходов. Служебные исходники первоначального Worker/Drizzle-шаблона оставлены для полноты проекта; в статическом сайте они не используются.

История внутреннего репозитория, параметры доступа к прежнему хостингу, секреты, `node_modules` и готовые промежуточные сборки в проект не включены.
