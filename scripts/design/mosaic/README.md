# Studio personalization animation

Original live-mosaic motion restored from c3a5f72: sequential exit and entrance with vertical movement and subtle scale, retaining Studio's gray surface #303332. Original 2560×1200, 30 fps, 12-second seamless timing and twenty
Figma panel assets are preserved. Run `python3 render-mosaic.py` with Pillow and
ffmpeg installed, then copy live-mosaic-2k.mp4 and live-mosaic-poster.png to their
personalization-studio-smooth-2k.mp4 and personalization-studio-poster.png in public/media.
